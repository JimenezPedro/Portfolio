Instalación completa de Kali Linux

Guía práctica paso a paso — descarga, verificación, creación de USB booteable, instalación y configuración post-instalación.

Introducción

Esta guía te acompaña desde la descarga de la ISO oficial de Kali hasta los ajustes post-instalación. Antes de empezar: haz copia de seguridad de tus datos y lee cada paso con calma. Si vas a reemplazar un sistema existente, asegúrate de tener respaldo.

Aviso de seguridad: Descarga siempre la ISO desde la web oficial (kali.org) y verifica su firma/sha256 antes de usarla.

Requisitos recomendados

  • CPU x86_64 (64-bit) — arquitectura recomendada.
  • Al menos 4 GB de RAM (8 GB o más recomendado para tareas intensivas).
  • 40 GB de espacio en disco (más si vas a instalar muchas herramientas).
  • Puerto USB y unidad USB (8 GB o más) o unidad DVD si usas medios ópticos.
  • Conexión a Internet (recomendada durante la instalación para paquetes).

1) Descargar y verificar la ISO

Descarga

Ve a https://www.kali.org/get-kali/ y descarga la imagen ISO adecuada (normalmente Installer o Live 64-bit).

Verificar SHA256

En el sitio oficial encontrarás el SHA256 checksum. Descargado el archivo ISO y el checksum, en Linux/macOS: 

# Calcula sha256 del ISO
sha256sum kali-.iso

# Compara con el sha256 provisto en la web
Verificar firma GPG (recomendado)

Si la web provee una firma GPG, descarga también la firma y la clave pública del proyecto para verificar la autenticidad. 

# Importar clave pública del equipo de Kali (ejemplo genérico)
gpg --keyserver keyserver.ubuntu.com --recv-keys 

# Verificar la firma
gpg --verify kali-.iso.sig kali-.iso
Si la comprobación SHA o GPG falla, no uses la ISO: vuelve a descargarla o consulta la web oficial.

2) Crear USB booteable

Dependiendo de tu sistema operativo, tienes varias opciones:

Windows
  • Rufus — muy usado y sencillo (selecciona la ISO y el modo DD si te lo pide).
  • balenaEtcher — interfaz simple, menos opciones avanzadas.
# (No es un comando de Windows; usar la GUI de Rufus o Etcher)
macOS
  • balenaEtcher (recomendado por simplicidad)
  • o usar dd desde la terminal (avanzado):
# Encuentra el identificador del USB (ej. /dev/disk2)
diskutil list

# Desmonta el USB
diskutil unmountDisk /dev/diskN

# Escribe la ISO (reemplaza /dev/rdiskN y kali.iso)
sudo dd if=kali-.iso of=/dev/rdiskN bs=4M status=progress && sync
Linux
  • balenaEtcher o dd (igual que macOS).
# Identificar el dispositivo USB (ej. /dev/sdb)
lsblk

# Escribir la ISO (reemplaza /dev/sdX por tu USB)
sudo dd if=kali-.iso of=/dev/sdX bs=4M status=progress && sync
Usar dd es poderoso pero peligroso: asegúrate de apuntar al dispositivo correcto para no sobrescribir disco del sistema.

3) Ajustes BIOS / UEFI

  • Arranca el equipo desde la unidad USB. Normalmente tecla F12, Esc, F9 o similar.
  • Si tienes UEFI, desactiva temporalmente Secure Boot si el instalador falla a la hora de cargar drivers. (Kali puede soportar Secure Boot en algunas builds, pero si tienes problemas, desactívalo).
  • Asegúrate de que el modo de arranque está en UEFI o Legacy según tu preferencia.
  • Si quieres instalar junto a otro SO (dual-boot), consulta particionado manual y haz backups.

4) Instalación (Graphical/Installer)

Paso a paso (resumen)
  1. Arranca desde el USB y elige Graphical install o Install.
  2. Selecciona idioma, zona horaria y layout de teclado.
  3. Configura red (si estás en red con DHCP normalmente se configura sola).
  4. Configura el nombre de host (hostname) — por ejemplo kali.
  5. Configura usuario y contraseña: crea un usuario estándar (no root) y contraseña segura.
  6. Particionado del disco — elige Guided – use entire disk para instalación sencilla, o Manual para control total.
  7. Si te pide, instala GRUB en el dispositivo de arranque (p. ej. /dev/sda).
  8. Finaliza la instalación y reinicia retirando el USB.
Particionado (opciones)

- Guided - use entire disk: elimina todo y crea particiones automáticamente (rápido).
- Manual: usa LVM, cifrado de disco (recomendado si manejas datos sensibles) o particionado avanzado.

Si necesitas cifrar el disco: el instalador ofrece LUKS. Anota la passphrase en un lugar seguro: sin ella no podrás recuperar los datos.

5) Configuración post-instalación

Actualizar sistema
sudo apt update
sudo apt -y full-upgrade
sudo reboot
Instalar metapaquetes útiles

Los metapaquetes agrupan herramientas. Elige el que prefieras:

# Ejemplos (puede variar según la versión)
sudo apt install -y kali-linux-default
# o para una instalación más completa
sudo apt install -y kali-linux-large
# o instalar conjuntos concretos
sudo apt install -y kali-tools-top10
Los nombres de metapaquetes pueden cambiar entre versiones. Consulta apt search kali-linux si no aparecen.
Habilitar SSH (opcional)
# Instalar y habilitar OpenSSH
sudo apt install -y openssh-server
sudo systemctl enable --now ssh
sudo systemctl status ssh
Configurar usuario root (opcional)

Hoy en día Kali usa usuario normal por defecto. Si necesitas establecer contraseña para root:

sudo passwd root
# Para cambiar a root:
su - root
Mantener el uso de un usuario estándar y sudo es más seguro en la mayoría de casos.
Instalar herramientas adicionales (ejemplos)
# Ejemplos rápidos
sudo apt install -y git curl wget net-tools nmap python3-pip
# Instalar pip packages si los necesitas
pip3 install --user pwntools

6) Consejos y solución de problemas

Problemas comunes
  • No arranca desde USB: revisa la prioridad de arranque en BIOS/UEFI y prueba con otra herramienta para crear el USB (Etcher / Rufus).
  • Error con Secure Boot: desactívalo temporalmente en UEFI.
  • Problemas de red en instalación: prueba conectar por cable o configurar DNS manualmente.
  • Paquetes rotos: 
    sudo apt --fix-broken install
sudo dpkg --configure -a
Buenas prácticas
  • Activa cifrado si vas a manejar datos sensibles.
  • Usa contraseñas robustas y un gestor de contraseñas.
  • Mantén el sistema actualizado (apt update && apt full-upgrade regularmente).
  • Evita usar root de forma persistente; usa sudo cuando haga falta.
